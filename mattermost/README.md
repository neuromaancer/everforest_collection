# Mattermost

Mattermost custom themes using the [Everforest](https://github.com/sainnhe/everforest) color palettes. The six JSON files cover both dark and light palettes in hard, medium, and soft contrast.

## Installation

1. Open **Settings > Display > Theme** in Mattermost.
2. Select **Custom Theme**.
3. Copy the contents of the JSON file for the palette you want and paste it into **Copy and paste to share theme colors**.
4. Select **Save**.

See Mattermost's [custom theme examples and import instructions](https://docs.mattermost.com/end-user-guide/preferences/customize-your-theme#custom-theme-examples) for details.

Mattermost only offers built-in code block themes, so dark palettes select `solarized-dark` and light palettes select `solarized-light`.
